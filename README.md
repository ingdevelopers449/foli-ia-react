# FOLI AI - React Frontend

Este repositorio contiene el código fuente de la Landing Page de **FOLI AI**, una plataforma web interactiva de estudio adaptativo diseñada para niños con TDAH.

## Estructura
- `/frontend`: Contiene la aplicación construida con React y Tailwind CSS.

## Para iniciar en local:
1. `cd frontend`
2. `npm install`
3. `npm start`
